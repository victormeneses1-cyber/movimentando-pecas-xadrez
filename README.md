# Movimentando as Peças do Xadrez 

Este projeto simula o movimento das peças Torre, Bispo e Rainha utilizando estruturas de repetição em C.

##  Objetivo

Aplicar estruturas de repetição:
- for
- while
- do-while

##  Movimentos Simulados

- Torre: 5 casas para a direita (for)
- Bispo: 5 casas na diagonal (Cima Direita) (while)
- Rainha: 8 casas para a esquerda (do-while)

##  Como compilar

```bash
gcc xadrez.c -o xadrez
./xadrez
